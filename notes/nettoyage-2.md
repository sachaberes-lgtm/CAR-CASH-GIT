## Garde-fous découverts en route (utiles pour la suite)
- Le grand script est une IIFE : seuls les `window.*` sont visibles de l'extérieur ; une fonction à zéro lecture n'est donc atteignable que par un `window.x=` ou par un OUTIL qui extrait du texte de index.html (les `ROBLOX/outils/cuire-*.js` lisent index.html par repères de ligne : `const SHAPES={`, `/* ===== LA GAMME DES 50 — FIN`, `SHAPES.lingot=`… ces repères n'ont pas bougé ; ces fichiers ne sont PAS dans le checkout creux, ils sont lus par `git show :chemin`).
- Les blocs balisés `/* <<<X>>> … <<<FIN X>>> */` (25 repères) sont extraits par des outils (boite-singe.html : VITRAIL/SINGE). retire.cjs refuse tout retrait qui contient ou avale un repère ; compte vérifié : 25 avant, 25 après.
- `(function paintSnake(){…})()` est une IIFE nommée, pas une fonction morte : l'inventaire du premier agent la comptait à tort (corrigé dans cn.cjs : seules les FunctionDeclaration sont candidates).
