# CASH CAR 🏁💰 — v1.0

Runner arcade 3D de voltige en **une seule vie** : fonce sur une autoroute suspendue dans le ciel, saute, vrille, amasse une fortune démesurée… la moindre chute et la voiture **explose**.

## ▶️ Jouer

Double-clique sur **`index.html`** (Chrome / Edge / Firefox). Clique ou appuie sur une touche pour lancer.
Connexion internet requise au premier chargement (Three.js + police via CDN). Clavier obligatoire.

| Touche | Action |
|---|---|
| `Z` / `↑` | Accélérer |
| `S` / `↓` | Freiner · piquer (en vol) |
| `Q` `D` / `←` `→` | Tourner · vriller (en vol) |
| `Espace` / `Shift` | Nitro (sol + réacteur aérien) |
| `R` | Se replacer |
| `Entrée` | Rejouer |
| `P` | Pause |

## 🎯 En bref

- **14 voitures** à débloquer à l'argent, de l'épave rouillée à la **COMÈTE 👑** (657 km/h), chacune avec son moteur, son look et sa brillance.
- Pièces d'or (combos), sphères de nitro, pads turbo colorés, dos d'âne, plots orange à envoyer valser, **flaques d'huile** qui font chasser la caisse.
- Sauter paye : atterris une figure et le verdict tombe — **MONSTRE**, **DOUBLE MONSTRE** ou **TRIPLE MONSTRE**.
- Tous les **×10 de score** à partir de 10 000 $ : pluie de devises du monde entier.
- Top 10 local avec saisie du nom (stocké dans le navigateur).
