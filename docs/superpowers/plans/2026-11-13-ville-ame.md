# La ville qui se visite — plan d'exécution

> Exécution : en natif (Sacha : « en une fois, très optimisé, prends ton temps, pas de bug »). Spec : `docs/superpowers/specs/2026-11-13-ville-ame-design.md`.

**But** : la route de Crypto City (nuit `MC==='ville'`, jour `MC==='crypto'`) devient une suite de scènes route + bâtiment, reliées par des virages légers qui montent et descendent, avec du dévers.
**Architecture** : un nouveau morceau `code/maps/ville-scenes.js` (drapeau, dévers, modules de route via un contexte `G`, réservations et bâtisse du décor) ; des raccords courts dans `ville-entree.js` (genCtrl1), `jade-balade.js` (buildVoxCity), `depart-avance.js` (pisteRoute), `ville-v3.js` + `cryptocity.js` (drapeau « sans pied »), `continuite.js` (pluie sous les toits).

## Contraintes globales
- `?sans=villeame` : la ville v1559 au tirage près (toute nouveauté derrière `VAME` / `VILLE_AME`, tirages seulement dans ses branches).
- Aucune matière ni programme neuf ; volumes dans `corps` (familles existantes), néons dans `neon` ; seuls les portiques ont une InstancedMesh (matière néon existante).
- ALLEGE/PAL seulement pour retirer de l'image ; jamais IS_MOBILE. La structure dure est la même partout.
- Les volumes de scène s'ajoutent après toutes les tours (aucun tirage `vr` décalé).
- Français, sections `/* ===== TITRE (date, qui : « demande ») ===== */`, pas de `//` en milieu de ligne dans le nouveau code.

## Points de vigilance (non couverts par un test dédié)
1. Un module calé sur la trame dont le virage de calage tombe sous 24° (douille) → il devient un vrai virage de 66-114°.
2. Le lissage des pentes (adoucirPentes/lisserRaccords/adoucirCretes) déplace les `y` : toute hauteur de décor se lit sur les `pts` FINAUX.
3. Une autre route qui traverse l'emprise d'un bâtiment de scène → la pièce est abandonnée (comptée), jamais posée à travers la route.
4. Un saut (`vSaute`) dans une zone de dévers → dévers forcé à 0 autour des raccourcis, de l'entrée, des crêtes et de l'arrivée.
5. Le pré-bâti : `VILLE_BANK.N` est lu juste après `genCtrl` dans `pisteRoute` (sans `yield` entre les deux).
