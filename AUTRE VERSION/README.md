# CASH CAR — AUTRE VERSION (la version PC fusionnée)

Le même jeu que `VERSION PRINCIPALE`, avec le **menu desktop** sur l'ordinateur (TOP 10, PLAY, GARAGE,
SETTINGS…). Sur un vrai téléphone, il s'ouvre quand même en version téléphone.

⚠ **Ce dossier est une COPIE générée — ne pas le modifier à la main.** Toute modification se fait dans
`VERSION PRINCIPALE`, puis `node synchro-versions.js` (à la racine du dépôt) recopie tout ici en ne
changeant qu'une ligne : `const EDITION='pc'`.

## Jouer
- Windows : double-clic sur `JOUER.bat` (les sons ne marchent bien qu'avec lui, pas en double-cliquant `index.html`)
- Mac / Linux : `python3 -m http.server 8000` dans ce dossier, puis http://localhost:8000
