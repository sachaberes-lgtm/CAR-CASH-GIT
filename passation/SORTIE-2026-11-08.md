  A gameplay / moteur / rendu · B interface / textes / écrans · C économie / sauvegarde / missions / voitures / son. Chaque point est relu contre le code actuel (beaucoup
  étaient déjà corrigés) puis corrigé avec preuve, ou rangé en « déjà corrigé » / « à trancher ».

  par ces deux drapeaux, qui coupent justement ce qu'un nouveau joueur traverse. Voir la mémoire du projet `banc-premiere-visite-pilote`.
